Qualtrics Resources

This page collects small scripts and code snippets for enhancing Qualtrics surveys. Each functionality has downloadable code and instructions for use. I am not a JavaScript specialist so codes may be imperfect, but these can provide a useful starter.

Description:This script creates a constant sum slider, useful for allocation problems without requiring participants to type. It lets you select categories and maximum allocation values that generate a set of sliders with a constant sum. Useful for time-allocation or belief elicitation questions. The Next button is disabled until the sum of the sliders equals the maximum value. You can customize to choose to “clamp” or “proportional”ly adjust the sliders once they reach the maximum allowed value. Choices are stored as embedded data using a prefix followed by the index of the choice – e.g., for 4 sliders and a prefix of “choice”, the embedded data becomes “choice1”, …, “choice4”. Tested for the new Simple Layout Qualtrics theme – be aware that embedded data saved must be preffixed by “_js”.

Description:This script allows you to embed a YouTube video in a Qualtrics survey and track the time spent on the video. It uses the YouTube IFrame API to control the video playback and send tracking data to Qualtrics. The script includes functions to start and stop tracking when the video is played or paused, and it sends the tracking data as embedded data to Qualtrics. The script also includes a function to handle the end of the video and send the final tracking data. This script is useful for surveys that include video content and want to measure participant engagement with the video. You have to add the HTML code to the question body and the JavaScript code to the question’s JavaScript section. The video ID must be specified in the HTML code. Also useful if you want to randomize videos and send the ID through Embedded Data.

### }}} **Description**:This script links a standard Qualtrics slider to a custom iframe visualization showing 1,000 dummy figures. As the respondent moves the slider, the script lights up one figure for every N units (e.g., every 5 units in the slider), offering a visual way to express estimates or beliefs. It uses `postMessage` to send data from the slider to the iframe hosted externally. This makes it easier for participants to engage with abstract numbers by visualizing them as people being selected. The script includes safeguards to check if the slider and iframe are correctly loaded. You can customize the number of total figures (`numDummies`) and the step size for when each new figure lights up. Works with the Simple Layout in Qualtrics. This requires a website (e.g., a personal website hosted on GitHub) to host the HTML. - **Resources**: - [Open slider-dummy-question-html.txt](../assets/qualtrics-resources/slider-dummy-question-html.txt) ``[Download]`` - [Open slider-dummy-js.txt](../assets/qualtrics-resources/slider-dummy-js.txt) ``[Download]`` - [Open slider-dummy-external-html.txt](../assets/qualtrics-resources/slider-dummy-external-html.txt) ``[Download]``
